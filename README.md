# Ôn Tập & Khám Phá Đại Lượng - Toán Lớp 4 (Kết Nối Tri Thức)

Trang web ôn tập và làm bài tập tương tác môn Toán lớp 4 (bộ sách Kết nối tri thức với cuộc sống).

## Nội dung bài học:
- **Đơn vị đo khối lượng**: Yến, tạ, tấn, kg, g.
- **Đơn vị đo diện tích**: m², dm², cm², mm².
- **Đơn vị đo độ dài**: km, m, dm, cm, mm.
- **Đơn vị đo thời gian mới**: Giây và Thế kỉ (cách xác định năm thuộc thế kỉ nào qua chữ số La Mã).
- **Hệ thống bài tập tự luyện**: Trắc nghiệm, điền số, so sánh, bài toán có lời văn thực tế có chấm điểm tự động.

Trang web chính thức cho học sinh: https://thien-0408.github.io/toan-lop-4/
